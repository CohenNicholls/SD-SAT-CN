### What features could your software include?

* reminders for missing work
* quick buttons to change status
* class filters
* student search
* overdue alerts
* colour coded statuses
* late work checklist
* simple reports for teachers
* dashboard showing all classes
* maybe notifications or popups
* history of changed submissions
* “needs review” section
* automatic sorting by due date

### What could it look like?

* simple dashboard layout
* sidebar with classes and assignments
* tables with student names and statuses
* red/orange/green colour coding
* big buttons for quick updates
* clean teacher-friendly design
* maybe dark mode
* boxes/cards showing missing work totals
* popup reminders
* basic graphs or charts

### How might users interact with it?

* click on a class to see submissions
* press buttons to update statuses
* filter by missing or late work
* search for students quickly
* receive reminders for overdue tasks
* scroll through assignments like Canvas
* import student data manually or through files
* use dropdown menus and checkboxes
* generate summaries before reports
