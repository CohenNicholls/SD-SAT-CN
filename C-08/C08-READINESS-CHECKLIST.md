# C08 — Assessment Readiness Checklist

Complete every section before your C08 assessments.

---

# 1. Alpha Testing

- [ ] I have a testing table with a **range of tests**.
- [ ] I tested normal/valid input.
- [ ] I tested invalid input.
- [ ] I tested at least one boundary or unusual case.
- [ ] I tested at least one validation rule.
- [ ] Each test has a specific expected result.
- [ ] Each completed test has a specific actual result.
- [ ] I have genuinely used debugging statements while testing.
- [ ] I have genuinely used a breakpoint while testing.
- [ ] Failed tests include the corrective action I took.
- [ ] My C08-1 evidence uses the required `# C8-1-X` labels.
- [ ] My testing evidence is committed to GitHub.

# 3. My Design Modification

- [ ] I identified a design that changed.
- [ ] I have evidence showing the design **BEFORE** the change.
- [ ] I have evidence showing the design **AFTER** the change.
- [ ] My annotation clearly explains what changed.
- [ ] I can name the **specific test result or feedback** that caused the change.
- [ ] I can explain why the modified design is better.
- [ ] I updated my evaluation criteria if the modification affected them.
- [ ] My design-modification evidence is committed to GitHub.

I can explain:

> **TEST RESULT → DESIGN PROBLEM → MODIFICATION → IMPROVEMENT**

# 5. Before C08-1 Recording

- [ ] My real SAT project is ready.

- [ ] My Git log is ready to show.

- [ ] My AI disclosure log is up to date.
- [ ] I know what I am going to demonstrate.
- [ ] I will narrate continuously.
- [ ] I will show an unbroken failing test → debugging → fix → re-test cycle.

> **SHOW → FAIL → DEBUG → FIX → PASS**
