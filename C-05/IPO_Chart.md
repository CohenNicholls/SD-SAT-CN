# IPO Chart (Input – Process – Output)

## Late Work Management System

| **Input**                                                | **Process**                                 | **Output**                                  |
| -------------------------------------------------------- | ------------------------------------------- | ------------------------------------------- |
| Assignment data imported from Canvas or entered manually | Validate assignment and student information | Assignment records stored in system         |
| Student names and IDs                                    | Store and retrieve student records          | Display student information                 |
| Assignment names and due dates                           | Compare due dates with submission dates     | Missing, Late, or Submitted status assigned |
| Teacher updates submission status                        | Save status changes to database/file        | Updated submission status displayed         |
| Filter selections (Class, Student, Status)               | Apply filtering algorithms                  | Filtered assignment list shown              |
| Search terms entered by teacher                          | Search assignment records                   | Matching assignments displayed              |
| Existing assignment records                              | Generate dashboard summaries                | Dashboard view updated                      |
| Outstanding missing work records                         | Check for unresolved submissions            | Reminder notifications generated            |
| Reminder settings                                        | Create and schedule reminders               | Teacher notified of pending updates         |
| Status updates made by teacher                           | Log changes to history records              | Status history maintained                   |
