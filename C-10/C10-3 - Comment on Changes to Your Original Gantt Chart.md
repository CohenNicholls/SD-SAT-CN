Main Differences Between the Original Plan and Actual Project
1. The project continued beyond the planned August completion date

The original Gantt chart planned the final Solution Evaluation stage for August 2026. However, beta testing was completed in September, including testing recorded on 10 September 2026.

Why it changed:
The project required additional development, refinement and testing before it was ready for beta testing.

Effect:
This delayed the project compared with the original timeline, but it allowed more time to identify usability problems and collect feedback from different testers.

Overall effect: Helpful for software quality, but it made the project take longer than planned.

2. Testing occurred later than originally planned

The Gantt chart planned testing for approximately 20-27 July 2026, while actual beta testing occurred later.

Why it changed:
The finished software needed to be developed and refined before testers could use the final version. Additional development work meant that testing moved later.

Effect:
Testing was delayed, but the later testing provided useful feedback about the actual finished software.

Overall effect: Helpful for identifying real problems, but it reduced the amount of time available after testing to make improvements.

3. Documentation and evaluation occurred later than planned

The original Gantt chart scheduled Documentation, Evaluation Strategy and Solution Evaluation during late July and August. Because testing continued into September, these final evaluation activities also occurred later than originally planned.

Why it changed:
The evaluation depended on having a finished product and usable beta-testing results.

Effect:
The project was completed later than expected, but the evaluation was based on actual testing and user feedback rather than assumptions.

Overall effect: Helpful for producing more accurate evaluation evidence, although the original schedule was too optimistic.

Good Decisions and What I Would Do Differently

The decision to continue testing and collect feedback before finalising the evaluation was useful because it identified real problems with login, input instructions, button visibility and filtering.

However, next time I would allow more time for development and testing in the original Gantt chart. I would also include a buffer between development and the final evaluation so that unexpected problems do not push the whole project behind schedule.
